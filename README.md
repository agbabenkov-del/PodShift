# PodShift

Небольшая Windows-утилита для быстрого переключения AirPods.

## MVP 0.1

Сейчас приложение:
- ищет AirPods среди уже спаренных Bluetooth-устройств;
- показывает имя устройства;
- показывает статус подключения;
- открывает системные Bluetooth-настройки для подключения/отключения;
- собирается в облаке GitHub Actions в self-contained Windows build.

## Важное ограничение 0.1

Windows не предоставляет простой универсальный публичный вызов вида
`ConnectBluetoothAudioDevice(deviceId)` для уже спаренного аудиоустройства.

Поэтому первая версия честно проверяет устройство и статус, а прямое one-click
подключение будет следующим техническим этапом.

## Как загрузить на GitHub

GitHub не распаковывает ZIP в репозиторий автоматически.

1. Распакуй `PodShift_0.1_GitHub.zip`.
2. В пустом репозитории GitHub выбери `Add file` → `Upload files`.
3. Перетащи **содержимое** распакованной папки, включая `.github`.
4. Нажми `Commit changes`.
5. Открой вкладку `Actions`.
6. Запусти `Build PodShift for Windows`.
7. После успешной сборки скачай artifact `PodShift-win-x64`.

## Скины

Внизу окна доступен переключатель «Скин»:

- **Обычный** — светлый интерфейс, используется при первом запуске.
- **Ретро 95** — серые объёмные кнопки, синяя строка заголовка,
  квадратные рамки и моноширинный логотип в духе Windows 95 и раннего интернета.

Скин меняется сразу, без перезапуска и повторного поиска AirPods.
Выбор хранится локально в `%LOCALAPPDATA%\PodShift\settings.json`.
Если файл отсутствует или повреждён, приложение запускается с обычным скином.
Если выбор невозможно сохранить, скин работает до закрытия приложения,
а подсказка переключателя сообщает об ошибке сохранения.

Оба скина используют одни обработчики Bluetooth. Подключение и отключение
в версии 0.1 по-прежнему выполняются через системные настройки Windows.

### Проверка интерфейса в Windows

1. При первом запуске проверить обычный скин и доступность поиска.
2. Выбрать «Ретро 95»: проверить заголовок, перетаскивание окна,
   сворачивание, закрытие и сочетание Alt+F4.
3. Найти AirPods, затем переключить скин: имя, статус и доступность кнопок
   должны сохраниться.
4. Проверить Tab, Space/Enter на кнопках, Alt+Down и стрелки в списке скинов.
5. Закрыть приложение и открыть снова: выбранный скин должен восстановиться.
6. Проверить оба скина при масштабе Windows 100%, 150% и 200%,
   с длинным именем устройства и многострочным сообщением.
7. При закрытом приложении повредить settings.json и запустить снова:
   должен загрузиться обычный скин.
